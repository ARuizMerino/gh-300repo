## Aplicación de Administración de Productos

Esta aplicación en Python permite gestionar productos mediante una interfaz web construida con Flask. Incluye operaciones CRUD: Crear, Leer, Actualizar y Eliminar productos.

### Características
- Agregar nuevos productos con nombre, precio y cantidad
- Listar todos los productos en la página web
- Actualizar información de productos existentes
- Eliminar productos
- Interfaz web accesible desde un navegador

### Archivos
- `product.py`: Define la clase Product
- `main.py`: Contiene la lógica principal y la aplicación web Flask

### Cómo ejecutar
Ejecuta el siguiente comando en la terminal:
```
python main.py
```

Esto iniciará un servidor web local. Abre un navegador y ve a `http://127.0.0.1:5000/` para interactuar con la aplicación.
